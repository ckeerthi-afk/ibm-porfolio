- Technician
- Supervisor
- Manager
- Administrator

Concept 02

Demo Workspace

Pre-populated assets, work orders, and sample data allow users to explore the product without setup anxiety.

Interactive behavior:
Toggle between Empty Workspace and Demo Workspace.

---------------------------------------------------

Concept 03

Checklist Onboarding

A guided checklist that breaks onboarding into achievable milestones.

Example tasks:
- Create your first asset
- Create a work order
- Invite your team
- Download mobile app

Interactive behavior:
Users can complete tasks and watch progress increase.

---------------------------------------------------

Concept 04

Guided Walkthroughs

Contextual guidance that teaches features during real workflows rather than through documentation.

Interactive behavior:
Display onboarding callouts over interface screens.

---------------------------------------------------

Concept 05

Progressive Disclosure

Reveal complexity only when users are ready.

Interactive behavior:
Show a simple interface gradually expanding into a more advanced workspace.

Concept 06

Feature Discovery

Introduce capabilities at meaningful moments instead of exposing everything at once.

Interactive behavior:
